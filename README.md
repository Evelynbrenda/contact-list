# Contact-List

Aplicativo mobile feito com React Native e Expo para gerenciar contatos e iniciar chamadas a partir da lista cadastrada.

## Funcionalidades

- Listagem de contatos salvos
- Cadastro de novos contatos
- Abertura da tela de chamada ao tocar no contato ou no icone de telefone
- Exclusao de contatos
- Interface simples e focada no fluxo de ligacao

## Tecnologias

- React Native
- Expo
- Expo Router
- TypeScript

## Como rodar o projeto
Instale as dependencias:

  npm install
  
  Se preferir, voce tambem pode usar yarn install ou pnpm install.

Inicie o projeto:

  npx expo start
  
  Abra no ambiente desejado:
  
  Android Emulator
  iOS Simulator
  Expo Go
  Web
